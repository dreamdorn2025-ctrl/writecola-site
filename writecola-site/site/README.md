# WriteCola — Сайт приложения для писателей

Современный сайт приложения **WriteCola**: главная промо-страница с интерактивным деревом сюжета и симулятором спринта + отдельный каталог видеоуроков (`tutorials.html`) с поиском, фильтрами по темам, модальным видеоплеером и живыми счетчиками посещений и скачиваний.

---

## 📂 Структура проекта

```
index.html              — Главная страница (Hero, фичи, спринт-демо, блок скачивания, FAQ)
tutorials.html          — Отдельный каталог видеоуроков (поиск, темы, таймкоды, плеер)
css/
  ├── style.css         — Главная дизайн-система (Modern Literary Tech)
  └── tutorials.css     — Стили каталога видеоуроков и модального плеера
js/
  ├── script.js         — Скрипты главной (дерево сюжета, спринты, живые счетчики)
  └── tutorials.js      — Движок видеоуроков (поиск, фильтры, таймкоды, localStorage)
content/
  ├── site-content.json — База данных: видеоуроки + параметры скачивания
  └── media/            — Логотипы (logo.svg, favicon.svg) и обложки уроков
downloads/              — Папка для архивов приложения
```

---

## ⚡ Живые счетчики (Посещения и Скачивания)

В сайт встроены автоматические счетчики в реальном времени:
1. **Счетчик просмотров/визитов**: автоматически фиксирует каждое уникальное посещение сайта.
2. **Счетчик скачиваний**: автоматически увеличивается при каждом клике на кнопку «Скачать WriteCola» или прямую ссылку на архив.
3. **Отображение**: данные в реальном времени отображаются в блоке статистики, бейдже над кнопкой скачивания и в подвале сайта.

## 🎬 Как добавлять новые видеоуроки

Все уроки хранятся в файле `content/site-content.json` в массиве `"tutorials"`.

Чтобы добавить новое видео, просто откройте `content/site-content.json` и добавьте объект:

```json
{
  "id": "new-lesson-slug",
  "title": "Название вашего видеоурока",
  "description": "Краткое описание урока для писателей.",
  "category": "versioning",
  "categoryLabel": "Git для книги",
  "level": "Базовый",
  "duration": "08:30",
  "videoUrl": "https://www.youtube.com/watch?v=ВАШ_КОД",
  "image": "content/media/guide-placeholder-1.svg",
  "featured": true,
  "timestamps": [
    { "time": "00:00", "title": "Введение" },
    { "time": "02:15", "title": "Практика" }
  ]
}
```

> **Поддерживаемые ссылки на видео:**
> - YouTube (включая видео «Доступ по ссылке»)
> - RuTube
> - VK Видео
> - Vimeo
> - Прямые `.mp4` файлы

## 🚀 Публикация в интернет (Netlify / GitHub Pages)

1. Загрузите файлы репозитория на GitHub.
2. В [Netlify](https://www.netlify.com) нажмите **Add new site → Import an existing project → Deploy with GitHub**.
3. Нажмите **Deploy site** (Build command оставить пустым). Сайт сразу заработает онлайн!
