# WriteCola — сайт-визитка приложения

Готовый одностраничный сайт: главная страница + раздел с фото/видео-инструкциями,
которые можно добавлять самостоятельно через панель `/admin`, + кнопка скачивания
архива с приложением.

Технологий и сборки нет — это обычный HTML/CSS/JS, который можно открыть
даже двойным кликом. Ниже — как вывести его в интернет бесплатно, шаг за шагом.
Регистраций и оплат не потребуется (кроме своего домена, если захотите).

---

## Что где лежит

```
index.html              — сама страница
css/style.css            — стили
js/script.js              — подгружает контент из content/site-content.json
content/site-content.json — данные: список инструкций + инфо о скачивании
content/media/            — картинки для инструкций (сюда же CMS будет класть фото)
downloads/                 — сюда можно положить .zip с приложением (если он небольшой)
admin/                     — панель управления сайтом (Decap CMS)
```

---

## Шаг 1. Выложите файлы на GitHub

1. Зайдите на github.com и зарегистрируйтесь (если ещё нет аккаунта).
2. Нажмите **New repository**, дайте имя, например `writecola-site`, сделайте
   его **Public**, кнопку "Add README" не нажимайте (README уже есть).
3. На странице пустого репозитория нажмите **uploading an existing file** и
   перетащите туда всю папку сайта (все файлы и подпапки целиком).
4. Нажмите **Commit changes**.

Гит через терминал не нужен — всё делается через веб-интерфейс.

## Шаг 2. Разместите сайт на Netlify (бесплатно)

1. Зайдите на netlify.com, зарегистрируйтесь через свой GitHub-аккаунт.
2. **Add new site → Import an existing project → Deploy with GitHub.**
3. Выберите репозиторий `writecola-site`.
4. Build command оставьте пустым, Publish directory — `/` (корень).
5. Нажмите **Deploy site**.

Через минуту сайт уже будет доступен по адресу вида
`https://случайное-имя.netlify.app`. В настройках **Site configuration → Domain
management** можно сразу переименовать поддомен на что-то вроде
`writecola.netlify.app`, а позже — подключить свой домен.

## Шаг 3. Включите панель управления `/admin`

Панель `/admin` позволяет добавлять инструкции и менять ссылку на архив прямо
из браузера, без правки кода.

1. В Netlify откройте ваш сайт → **Identity** → **Enable Identity**.
2. Там же, в **Identity → Registration**, выберите **Invite only**
   (чтобы регистрироваться в панели могли только приглашённые вами люди).
3. Откройте **Identity → Services → Git Gateway** и нажмите **Enable Git Gateway**.
   Это разрешает панели сохранять изменения обратно в ваш GitHub-репозиторий.
4. Вернитесь в **Identity → Invite users**, введите свою почту и отправьте
   приглашение. Придёт письмо — перейдите по ссылке и задайте пароль.
5. Откройте `https://ваш-сайт.netlify.app/admin/`, войдите под этой же почтой —
   и вы в панели: разделы **«Инструкции»** и **«Скачивание»**.

В панели:
- **Инструкции** — добавляете карточку: заголовок, описание, тип (фото или
  видео) и либо картинку (загружается прямо туда), либо ссылку на видео
  (YouTube/Vimeo — см. ниже почему не файл).
- **Скачивание** — версия, размер, платформа и ссылка на архив.

Каждое сохранение в панели автоматически создаёт коммит в GitHub, а Netlify
сам пересобирает и обновляет сайт за 10–30 секунд.

### Если панель не нужна — самый простой вариант

Можно обойтись без `/admin` вообще: просто открывайте файл
`content/site-content.json` прямо на GitHub (кнопка карандаша — «редактировать»),
вручную правьте текст по образцу, жмите **Commit changes** — Netlify сам
пересоберёт сайт. Это чуть менее удобно, но не требует шага 3 совсем.

## Шаг 4. Как выложить архив с приложением

Есть два случая:

**Архив небольшой (до ~90 МБ).**
Положите `.zip` в папку `downloads/` (через тот же веб-загрузчик GitHub), а в
`content/site-content.json` (или в панели `/admin` → «Скачивание» → «Ссылка на
архив») укажите `downloads/имя-файла.zip`.

**Архив большой (обычное дело для десктоп-приложений).**
GitHub не хранит файлы больше 100 МБ в обычном репозитории, поэтому архив
нужно положить отдельно:
- **GitHub Releases** — в репозитории вкладка *Releases → Create a new release*,
  прикрепите .zip (до 2 ГБ бесплатно), скопируйте прямую ссылку на файл.
- или **Google Диск / Яндекс.Диск** — загрузите файл, откройте доступ «по
  ссылке», используйте прямую ссылку на скачивание.

Готовую ссылку вставьте в поле «Ссылка на архив» в панели `/admin`.

## Проверить локально перед публикацией

Просто откройте `index.html` двойным кликом в браузере — раздел с
инструкциями и кнопка скачивания подтянут данные из `content/site-content.json`
и заработают как на боевом сайте.

## Что можно поменять быстро

- **Название и текст на главной** — прямо в `index.html`, там всё читаемым
  текстом на русском.
- **Цвета/шрифты** — переменные в начале `css/style.css` (блок `:root`).
- **Домен** — в Netlify: Domain management → Add custom domain, дальше
  прописать DNS у вашего регистратора (Netlify покажет, что именно вписать).
